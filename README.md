## 🚀 Features

| **Feature** | **Description** |
|:---|:---|
| **Truly Local** | Every token is generated on your machine — no network requests |
| **Native macOS** | Built with SwiftUI for a smooth, system-native experience |
| **Model Picker** | Download and switch between multiple Llama-format models easily |
| **No Account Needed** | Open the app and start chatting — zero sign-up, zero tracking |
